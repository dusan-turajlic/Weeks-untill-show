localizeFoods smoke test

Dev-only, opt-in (not linked from the app). Loads a real on-device model in this browser and shows what engine.localizeFoods() actually returns for a catalog language — so you can eyeball whether the model can translate English food names into local grocery terms. Needs WebGPU and network to the model CDN. The first run downloads the model (up to a few GB). Optionally also checks the real country catalog to show how many foods the English query misses vs. how many the local terms rescue.

Idle. Press a button to load the model.
